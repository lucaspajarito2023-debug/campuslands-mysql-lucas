# 2. Introducción

Este proyecto implementa una base de datos relacional para una academia técnica inspirada en **kickboxing**. El objetivo principal es practicar el uso de **FOREIGN KEY** en MySQL, garantizando la integridad referencial entre academias, peleadores y combates.

La solución fue desarrollada con enfoque profesional, utilizando nombres descriptivos, restricciones de negocio y consultas orientadas a análisis deportivo.

---

# 3. Objetivo del ejercicio

Desarrollar una solución ejecutable desde cero que permita:

* Registrar academias de kickboxing.
* Registrar peleadores y su academia.
* Registrar combates entre peleadores.
* Consultar indicadores deportivos.
* Mantener consistencia mediante llaves foráneas.
