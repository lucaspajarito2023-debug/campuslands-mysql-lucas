# 2. Introducción

Este proyecto desarrolla una base de datos relacional para una academia técnica inspirada en **kickboxing**. El propósito principal es practicar el uso de la sentencia **DELETE** de forma segura y controlada, evitando eliminaciones accidentales y respetando las relaciones entre tablas.

Además del DELETE, el ejercicio incluye:

* Diseño de tablas.
* Restricciones de integridad.
* Inserción de datos realistas.
* Consultas de análisis deportivo.
* Organización profesional de scripts SQL.

La solución fue construida pensando en que cualquier desarrollador pueda ejecutarla desde cero y comprender fácilmente cada decisión tomada.

---

# 3. Objetivo del ejercicio

Implementar una solución en MySQL que permita:

1. Registrar gimnasios de kickboxing.
2. Registrar peleadores y su información deportiva.
3. Consultar estadísticas útiles.
4. Aplicar un **DELETE controlado** basado en criterios específicos.
5. Mantener la integridad referencial de la base de datos.
